# FabricSort v3 (Keras CNN → Optuna → Streamlit) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild `fabric_classification.ipynb` so it screens 4 Keras CNNs, tunes the Top 1 with Optuna (before/after over 3 seeds), exports the best model, and writes a 3-page Streamlit `app.py`.

**Architecture:** Shared code (data loading, Keras model zoo, dataset, predictor) lives in `fabric_lib.py`, which the notebook writes from section 1.1 and the app imports. The notebook is generated by a builder script (`tools/build_notebook.py`), which reuses the EDA/split cells from the backup notebook so the existing split is reproduced exactly. All training runs go through one `train_one()` function that caches by `run_id`. The app only reads files in `results/` and `models/`.

**Tech Stack:** Keras 3 on `KERAS_BACKEND="torch"` (torch 2.14 + CUDA 12.6), Optuna (TPE + MedianPruner, SQLite), scikit-learn metrics, plotly, Streamlit ≥ 1.45 (`st.navigation`), pytest, nbformat/nbclient. Python 3.14 in the project `.venv`.

**Spec:** `docs/superpowers/specs/2026-10-30-keras-cnn-tuning-design.md`

## Global Constraints

- Python is `C:\Users\Natth\OneDrive\Desktop\ml\.venv\Scripts\python.exe`. Every process sets `KERAS_BACKEND=torch` **before** `import keras`.
- Classes, in this order: `["Cotton", "Polyester", "Silk", "Viscose"]`. Input is 224×224 RGB, values 0–255.
- Models: `ResNet50V2`, `DenseNet121`, `EfficientNetB0`, `ConvNeXtTiny`, all with ImageNet weights, `include_top=False`.
- Split: reuse `results/split.csv` (Train 4,887 / Val 326 / Test 328). Fingerprint check before training. Test is used only in section 10.
- Seeds: screening `42`; before/after `(42, 7, 2024)`.
- Default recipe: phase 1 freezes the base, trains the head 3 epochs at lr 1e-3. Phase 2 unfreezes the top 30% of layers, lr 1e-5 with cosine decay, at most 30 epochs, patience 7 on Val Macro-F1. Dropout 0.3, weight decay 1e-4, label smoothing 0, base augmentation, no MixUp, class-weighted loss. BatchNorm layers stay frozen.
- Optuna: 15 trials, 12 phase-2 epochs per trial, `TPESampler(seed=42)`, `MedianPruner(n_startup_trials=4, n_warmup_steps=3)`, storage `sqlite:///results/optuna.db`, study name `top1_<arch>`.
- Selection rule: highest Val Macro-F1. Within 0.01 → faster `infer_ms_per_img`.
- Fallback trigger: mean Test Macro-F1 of "after" < 0.85.
- `CONF_THRESHOLD = 0.60`. Mixed precision `mixed_float16`. Final Dense layer is `dtype="float32"`. Batch 32, falling back to 16 on OOM.
- User-facing text (markdown, app labels, messages) is in Thai, matching the existing notebook. Code identifiers are in English.
- This folder is **not** a git repo. Instead of commits, each task ends with a checkpoint: run the task's tests and append a line to `docs/superpowers/plans/progress.log`.

**Files:**

**Interfaces (Produces):**
- `CLASSES: list[str]`, `IMG_SIZE = 224`, `IMG_EXTS: set[str]`
- `load_pil(src: str | Path | bytes | PIL.Image) -> PIL.Image` (RGB, EXIF-transposed)
- `KERAS_ZOO: dict[str, dict]` with keys `"resnet50v2", "densenet121", "efficientnetb0", "convnexttiny"`. Each value is `{"name": str, "app": callable, "preprocess": "tf" | "torch" | "none"}`. Preprocess modes: ResNet50V2 `tf` (x/127.5−1), DenseNet121 `torch` (x/255, ImageNet mean/std), EfficientNetB0 and ConvNeXtTiny `none` (they preprocess internally).
- `@keras.saving.register_keras_serializable("fabric") class Preprocess(keras.layers.Layer)` with `__init__(mode)` and `get_config()`.
- `build_model(arch: str, dropout: float = 0.3, weights: str | None = "imagenet") -> keras.Model`, where the base layer is named `"base"`. The base is called with `training=False`. The head is GAP → Dropout → `Dense(4, softmax, dtype="float32")`.
- `set_trainable(model, unfreeze_frac: float) -> None`: `0.0` freezes the whole base. Otherwise the top `ceil(frac × n_layers)` base layers become trainable, but `BatchNormalization` layers always stay frozen.
- `class FabricSequence(keras.utils.PyDataset)` with `__init__(paths, labels, batch_size, train: bool, aug: "base" | "strong" = "base", mixup: bool = False, class_weights: np.ndarray | None = None, seed: int = 42)`. `__getitem__` returns `(x float32 [B,224,224,3] 0–255, y one-hot or soft [B,4], w [B])`, where `w = y @ class_weights` (all ones if `None`). Augmentation (PIL/numpy, train only): `base` = random resized crop scale (0.4, 1), 90° rotations, horizontal flip, color jitter (0.15, 0.15, 0.10, 0.02). `strong` = scale (0.25, 1), plus vertical flip, grayscale p 0.05, and random erasing p 0.25. Eval = resize the shorter side to 256, then center crop 224. `mixup=True` means each batch randomly gets MixUp (α 0.2) or CutMix (α 1.0). `on_epoch_end` reshuffles when training.
- `class KerasPredictor` with `__init__(model, classes=CLASSES)` and `predict_proba(images: list) -> np.ndarray [N,4]`, using the same eval transform as `FabricSequence(train=False)`.
- `load_predictor(model_dir: Path) -> KerasPredictor`. Reads `model_meta.json` (`framework` must be `"keras"`, otherwise raise `ValueError` with a Thai message), loads `meta["model_file"]`, and attaches `.meta`.
